Senior Project

Dancing Water Feature

Overview

Final test for the fountain running succesfully

As the software developer I designed and developed the software for a music-reactive dancing water fountain system using React Native, audio frequency analysis, and Bluetooth Low Energy (BLE) communication. I built the mobile application that captured and processed live audio data, then translated it into synchronized real-time water pump and LED lighting effects through communication with a microcontroller.

Initial Design

In the first phase of design, I developed a JavaScript web application that analyzed uploaded audio tracks using FFT processing and split the music into frequency bands. On the UI, users could select from uploaded music files and see a visualizer that represented the audio frequencies in real-time.

I refined and improved the original web application by adding adjustable sensitivity and threshold sliders to affect the audio processing, a color picker to preview LED effects on the visualizer, and means to connect to a microcontroller (Wi-Fi or COM port). The microcontroller connection would allow pumps to be turned on and off to react to the real-time audio data.

Mobile App

Due to issues with the web application (such as latency, reliable microcontroller communication, and portability), I decided to switch the design to a mobile application using React Native to better suit the team's needs.

Dance screen of the mobile application

The new design uses Android’s MediaProjection API to capture live audio from any app on the device for real-time music visualization and fountain control. The app processes audio using FFT and sends frequency data over Bluetooth Low Energy (BLE) as a bitmask to a microcontroller that controls the water pumps and LED lighting effects, creating a more responsive and portable music-reactive fountain system.

Lights

Using addressable LED lighting effects with the FastLED library on the microcontroller, I developed custom animations and real-time color transitions that reacted to music data sent from the mobile app over BLE. The app transmitted RGB color values and brightness information, which were processed and color-corrected to improve vibrancy and accuracy across the LED strips.

Microcontroller

Arduino Giga R1 microcontroller used for the project

I programmed an Arduino Giga R1 microcontroller to control music-reactive water pumps and addressable LED lighting using BLE communication and FFT audio data from the mobile application. The system used bitmask-based relay control for frequency-driven pump effects, FastLED animations, brightness modulation, and overheat monitoring to improve synchronization and overall reliability.
