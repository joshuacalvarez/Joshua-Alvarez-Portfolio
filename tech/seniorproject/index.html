Senior Project

Dancing Water Feature

Overview

As the software developer I designed and developed the software for a music-reactive dancing water fountain system using React Native, audio frequency analysis, and Bluetooth Low Energy (BLE) communication. I built the mobile application that captured and processed live audio data, then translated it into synchronized real-time water pump and LED lighting effects through communication with a microcontroller.

Initial Design

In the first phase of design, I developed a JavaScript web application that analyzed uploaded audio tracks using FFT processing and split the music into frequency bands. On the UI, users could select from uploaded music files and see a visualizer that represented the audio frequencies in real-time.

I refined and improved the original web application by adding adjustable sensitivity and threshold sliders to affect the audio processing, a color picker to preview LED effects on the visualizer, and means to connect to a microcontroller (Wi-Fi or COM port). The microcontroller connection would allow pumps to be turned on and off to react to the real-time audio data.

Mobile App

Due to issues with the web application (such as latency, reliable microcontroller communication, and portability), I decided to switch the design to a mobile application using React Native to better suit the team's needs.
